# ZeppHello — Zepp OS Mini-App Template & Builder
**By Stealth Apps**

A production-ready starter template and interactive testing environment for **Zepp OS 3.0 / 2.x** mini-apps targeting Amazfit smartwatches (Round 466x466 AMOLED screen, e.g. Amazfit Active 3 / Balance / GTR series).

---

## 🚀 Features

- **Interactive Watch Face (`page/index.js`)**: Interactive "Hello, Zepp OS!" UI that cycles vibrant AMOLED colors on tap with touch event tracking.
- **Shortcut Cards (`app-widget/index.js`)**: Quick glanceable card for the Amazfit negative/shortcut screen with tap-to-launch navigation.
- **Secondary Widgets (`secondary-widget/index.js`)**: Full-screen glanceable widget accessible by swiping left from the watchface.
- **Companion Service (`app-side/index.js`)**: Phone-side background service with full fetch capability and IPC messaging.
- **Zepp App Settings (`setting/index.js`)**: Smartphone settings UI using `AppSettingsPage` and `settingsStorage` to configure default text colors.
- **GitHub Actions & QR Installer (`scripts/generate-qr.js` & `.github/workflows/build.yml`)**: Automatically packages `.zab` and `.zpk` files on push and generates `zpkd1://` QR codes for direct installation via Zepp App Developer Mode.

## 📂 Codebase Architecture (Template Guide)

```text
├── app.json                  # Zepp OS Manifest (permissions, widgets, 466x466 target)
├── app.js                    # Global App lifecycle & shared globalData
├── page/
│   └── index.js              # Watch UI using hmUI canvas widgets (text, button, arc)
├── app-side/
│   └── index.js              # Phone background service (fetch, settings sync, IPC)
├── setting/
│   └── index.js              # Zepp App settings UI (color selection via settingsStorage)
├── app-widget/
│   └── index.js              # Shortcut Screen Card (API level 2.0+)
├── secondary-widget/
│   └── index.js              # Swipe-left secondary widget (API level 2.0+)
└── scripts/
    └── generate-qr.js        # Developer mode QR code generator (zpkd1:// protocol)
```

## 🛠️ Testing & Installation

### Option 1: Zepp App Developer Mode (Wireless QR Install)
1. In the **Zepp App**, go to **Profile > Settings > About** and tap the **Zepp logo 7 times** to activate Developer Mode.
2. Go to **Profile > [Your Watch] > Developer Mode**.
3. Tap the **QR Scanner icon** at top right.
4. Scan the `zpkd1://` QR code generated by the GitHub Actions build or local tester to flash wirelessly.

### Option 2: Local Development with Zeus CLI
```bash
npm install -g @zeppos/zeus-cli
npm install
zeus preview
```
